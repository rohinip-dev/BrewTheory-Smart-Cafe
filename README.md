## 📌 About

BrewTheory Smart Cafe is a full-stack web app that lets customers **browse the menu, book tables, place orders, and get a digital bill** — while giving admins full control over the café from a dashboard.

---

## ✨ What It Does

| Feature | Description |
|--------|-------------|
| 🪑 **Seating Map** | See which tables are free and book instantly |
| 📅 **Table Booking** | Pick a date, time slot & number of people |
| 🍽️ **Menu** | Browse Beverages, Snacks & Desserts |
| 🛒 **Cart** | Add food while booking |
| 🧾 **Bill** | Auto-generated bill with GST & service charge |
| 🛠️ **Admin Panel** | Manage tables, menu, and bookings |

---

## 🛠️ Built With

- **Frontend** — HTML, CSS, JavaScript
- **Backend** — Node.js, Express.js
- **Database** — MySQL
- **Auth** — JWT + bcrypt
